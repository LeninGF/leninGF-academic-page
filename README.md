# Lenin G. Falconi — Academic Profile Page

Personal academic website built with Flask. Hosts information about my research, publications, and professional background.

## Tech Stack

- **Backend:** Flask (Python)
- **Frontend:** HTML/CSS with dark/light mode toggle
- **Deployment:** Render.com (Flask) / GitHub Pages (static snapshot)

## Local Development

```bash
pip install -r requirements.txt
python app.py
```

Then open http://localhost:5000
